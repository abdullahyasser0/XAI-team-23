# Project README

## Overview

This project performs machine learning classification and model interpretation on a tabular dataset using a variety of models and explainability tools. It includes preprocessing, feature selection, and advanced explainability (e.g., LIME, SHAP, ALE).  
**GPU support is required** for optimal performance due to computationally intensive operations (e.g., SHAP values, model training, hyperparameter tuning).

## Requirements

- Python 3.8+
- NVIDIA GPU with CUDA support
- All packages listed below must be installed

## Dependencies
